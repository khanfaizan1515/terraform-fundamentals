\# Tutorial 1 – What is Infrastructure as Code with Terraform?



\## Key Learning



Infrastructure as Code (IaC) means managing infrastructure using configuration files instead of creating and configuring resources manually.



Terraform allows infrastructure to be defined using declarative configuration files and manages the required resources through providers such as AWS.



\## What I Learned



\- What Infrastructure as Code means

\- How Terraform manages infrastructure

\- Difference between manual infrastructure and IaC

\- Terraform configuration files use HashiCorp Configuration Language (HCL)
